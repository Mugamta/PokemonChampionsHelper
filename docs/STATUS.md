## 한 것

### 사용자 요청 사항
- **디자인 개편**: 게임 UI 스타일 (짙은 남색, 타입 색, 카드형 슬롯, 노랑/청록 강조색). 다크 단일 테마.
- **한/영/일 지원**: 화면 문구 `i18n/locales/*.json`, 게임 이름·설명은 PokeAPI 공식 명칭. 언어는 헤더에서 전환, localStorage `pch_lang` 에 저장.
- **데이터 키 영어 통일**: 포켓몬/기술/특성/도구/성격/타입/스탯/상태 전부 Showdown 식 영어 id.
- **포챔스 공식 스프라이트**: Bulbagarden Archives 의 인게임 메뉴/가방 스프라이트 512장 (포켓몬 346 + 도구 166).
- **레귤레이션 M-C**: 신규 24종(23종 + 알로라 페르시온), 메가 6종, 도구 12종 + 메가스톤, 기술 변경·금지 반영.
- **정리 범위**: 레거시 삭제, 더블 배틀 화면 신규, 도움말/소개/문의 작성, 싱글·더블 선출을 공용 컴포넌트로 통합.
- **검증**: 공식 공지 + Serebii 대조 ([KNOWN_ISSUES.md](KNOWN_ISSUES.md) "데이터 검증 현황").

### 동작이 예전과 달라진 것 (의도한 수정)
- 데미지: **타입 상성·자속 실제 적용** (예전엔 자속 항상 1.5, 상성 없음), 천하장사 1.5 → **2배**, 9세대 계산 순서·4096 반올림.
- 행동 순서 예측에 **우선도** 반영, 트릭룸이면 스피드 역산 반대로.
- 상태이상이 **포켓몬별**로 유지 (예전엔 진영에 하나), 교체 시 특수상태 초기화.
- 날씨·필드 특성(가뭄/~메이커 등) 등장 시 자동, 지속 연장 도구(바위류/그라운드코트/빛의점토) 자동 8턴.
- 더블에서 상대가 2마리 있으면 광역기 0.75배 자동.
- 선출 화면: 선출 전에는 파티 6마리 전체 기준으로 표 표시.
- 기술 PP 가 챔피언스 값(8/12/16/20)으로 정정됨.
- 예전 저장 파티(한글 이름)는 첫 접속 시 새 형식으로 자동 이전 후 예전 키 삭제.

## 하지 않은 것 (남은 작업)

우선순위 높은 순.

1. **main 병합·배포** — 사용자 확인 후. 병합 전에 사용자가 직접 화면을 써 보는 게 좋다.
2. **배틀 전용 폼 미지원**: 팔라피 마이티폼(실전에서 거의 항상 이 폼), 킬가르도 블레이드/실드 전환. 현재 팔라피는 노멀폼 수치로 계산된다.
3. **더블 배틀 단순화된 부분**: 도우미·프렌드가드 등 아군 효과 없음, 위협 자동 적용 없음, 아군을 맞히는 광역기(지진 등)의 아군 피해 계산 없음,
   ①②③ 분석과 "이번 턴 상태이상 발생"은 선택한 1:1 조합(focus)만 대상. 더블 화면은 싱글보다 테스트가 적다.
4. **계산 미반영 특성/도구**: [BATTLE_MECHANICS.md](BATTLE_MECHANICS.md) 목록에 없는 것들 (약점보험 발동 후 랭크, 기합의띠 생존 판정 등).
5. **테스트 범위**: `utils/`(계산)만 단위 테스트가 있다. `useBattle`/`useBattleAnalysis`(턴 진행·역산)와 화면 컴포넌트는 자동 테스트 없음 — 스크린샷으로만 확인.
6. **ESLint**: 설정이 TypeScript / `<script lang="ts">` 를 파싱하지 못해 새 코드는 lint 미검사 (typescript-eslint 추가 필요).
7. **예전 URL 리다이렉트 없음**: `/partySelect`, `/singleEntrySelect`, `/doubleEntrySelect`, `/singleBattle` 북마크는 404.
8. **모바일 배틀 화면**: 레이아웃은 반응형이지만 실제 휴대폰 폭에서 사용성 검토는 파티 화면만 했다.

### 예전 화면에 있었는데 빠지거나 바뀐 것 (사용자 확인 필요)
- 파티 화면의 **HP% 슬라이더** 없음 (예전에도 표시용이었음).
- 선출 화면 내 카드의 **메가진화 반영 체크박스** 없음 → 파티 화면의 메가 토글을 그대로 따른다.
- 배틀 화면 **대기 포켓몬의 메가 토글** 없음 → 필드에 나온 포켓몬 패널에서만 토글/사용.
- 배틀 화면 레이아웃을 새로 짰다 (내 쪽 왼쪽 / 가운데 필드·행동·예상 / 상대 오른쪽 / 아래 표 2개). 예전 6칸 배치와 다름.

## 다음 세션 시작 방법

```bash
git checkout redesign
npm install          # vitest 설치 때 npm 10.9 버그로 --legacy-peer-deps 를 썼음. 일반 install 은 정상
npm test             # 계산 엔진 (@smogon/calc 대조)
npm run dev          # http://localhost:3000
node scripts/verify-data.mjs --dex   # 데이터 검증 (scripts/.cache/serebii 캐시 사용)
```

주의:
- Windows Git Bash 에서 `NUXT_APP_BASE_URL=/PokemonChampionsHelper/` 를 줄 때는 `MSYS_NO_PATHCONV=1` 필수 (안 하면 모든 HTML 이 "Redirecting...").
- `npx nuxt dev` 를 백그라운드로 띄웠다가 셸만 종료하면 `nuxi dev` node 프로세스가 남아 포트/락을 잡는다 → 프로세스를 직접 종료.
- composable 의 타입만 `import type` 하면 같은 모듈 함수 자동 import 가 빠진다 → 함수도 명시적으로 import ([CLAUDE.md](../CLAUDE.md) 6번).
- 새 composable 파일을 추가하면 dev 서버가 자동 import 를 늦게 반영하는 경우가 있다.
- 게임 데이터는 `public/data` 를 직접 고치지 말고 `scripts/sources/` 수정 → `npm run build:data` → `node scripts/verify-data.mjs`.
