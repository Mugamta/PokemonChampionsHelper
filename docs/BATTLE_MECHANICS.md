# 배틀 계산 규칙

포켓몬 챔피언스 = 9세대 계산식, **레벨 50, 개체값 31 고정**, 노력치 대신 **능력 포인트(SP)**: 스탯당 최대 32, 합계 66.
근거: Showdown `data/mods/champions/scripts.ts`. 검증: `tests/damage.test.ts` 가 @smogon/calc(9세대)와 16개 난수 전부 일치하는지 대조,
`tests/battle.test.ts` 가 배틀 진행(폼 전환·위협·도구 소모·도우미/프렌드가드·턴 경과·되돌리기)을 확인
(SP → 노력치 환산 `EV = 8·SP − 4` 이면 레벨 50 실능치가 챔피언스 공식과 같아진다).

## 실능치 — `utils/stats.ts`

```
HP   = 종족값 + SP + 75            (종족값 1 = 껍질몬 → 1)
그 외 = floor((종족값 + SP + 20) × 성격)    성격 110/100, 90/100
랭크 배율: +n → (2+n)/2, −n → 2/(2+n)
```
실전 스피드(`effectiveSpeed`): 랭크 → 날씨 특성(쓱쓱/엽록소/모래헤치기/눈치우기/서핑테일) ×2 → 곡예(도구를 잃으면) ×2 → 속보 1.5 → 구애스카프 1.5 → 순풍 ×2 → 마비 0.5

## KO — `utils/ko.ts`

- `koChance`: 16개 난수 N회 합 분포 → 처음으로 KO 확률이 0보다 커지는 N (확정/난수 N타)
- 기합의띠 / 옹골참(틀깨기면 무시): 만피에서는 첫 타가 최대 HP−1 → 확정 N타·연속기 KO 시점에 반영 (`holdsOnAtFull`)
- 연속기는 히트별 누적으로 몇 타째 KO 인지(`koHitIndex`), 접촉 반격(까칠한피부/철가시 1/8, 울퉁불퉁멧 1/6) 시뮬레이션(`simulateMultiHit`)
- 상태이상 턴 종료 데미지: 독 1/8, 화상 1/16(내열 1/32), 맹독 n/16, 매직가드/포이즌힐 0
- HP 배수 판정(파티 화면): 재생력 3n → 포이즌힐 8n+1 → 먹다남은음식/검은진흙 16n → 대타출동 16n+1 → 씨뿌리기 8n−1 → 기본 16n−1
- 결정력(`powerIndex`) = 최종 위력 × 보정 후 공격 × 자속 × 날씨 × 화상 × 생명의구슬
- 내구 지수(파티 화면) = floor(H × B(또는 D) / 0.411)

## 배틀 화면 분석

- 상대 배분 시나리오(내 공격): 무보정 / H32 / H32·B(D)32 / H32·B(D)32 보정
- 행동 순서 (`useBattle.turnOrder`): 우선도(장난꾸러기·질풍날개·힐링시프트 포함) → 관찰한 선후공 → 스피드(트릭룸이면 역순, 매직룸이면 스카프 없음).
  메가진화는 행동 전에 모두 처리하므로 메가 후 스피드로 비교
- **상대 스피드 구간** (`utils/speedInference.ts`): 무보정 / 성격 보정 / 무보정+스카프 / 보정+스카프 4구간마다 가능한 스피드 SP 범위(0~32)를 둔다.
  같은 우선도에서 관찰한 선후공 = "상대 실전 스피드 ≥ / ≤ 내 스피드" → 랭크·순풍·마비·특성(쓱쓱 등)·곡예를 반영한 실전 스피드로 바꿔
  구간마다 SP 범위를 교집합으로 좁힌다 (동속은 양쪽 다 가능). 남은 구간으로 결론: 스카프 확정/아님, 성격 보정 확정/무보정 확정, 모두 불가(입력 확인).
  변신한 상대는 복사한 스피드 기준(스카프 유무만). 스피드 하락 성격은 다루지 않음
- **상대 배분 추정** (`utils/statInference.ts`, `composables/useOppEstimate.ts`): 턴을 적용할 때 관측을 저장
  (기술·입력 데미지·급소·양쪽의 그 시점 폼/랭크/상태/HP/도구 소모·필드·상황 옵션).
  - 내가 준 데미지(%) → (HP SP 0~32) × (방어 또는 특방 SP 0~32) × (성격 −/무/+) 격자에서 16개 난수 중 하나가 입력 ±1%p 인 칸만 남김.
    쓰러뜨렸으면 최대 난수 ≥ 남은 HP 만 확인. 원더룸이면 반대 능력치
  - 내가 받은 데미지(HP) → (공격·특공 SP) × (성격) × (도구 후보: 없음 / 생명의구슬 / 달인의띠 / 힘의머리띠 / 박식안경 / 그 타입 강화 도구) 격자,
    난수 중 하나가 입력 ±1 HP. 상대 도구를 입력해 두었으면 그 도구 하나로만. 스피드가 스카프 확정이면 데미지 도구 제외,
    데미지 도구가 확정되면 "스카프 아님"
  - SP 합 66: 스피드·공격에 확실히 쓴 SP 를 빼고 남은 만큼만 HP·방어·특방 조합 허용
  - 제외: 연속기, 고정 데미지 기술, 변신한 상대, 피격 시 발동 도구를 쓴 턴. 상대 특성은 입력값 기준

## 배틀 진행 자동 반영 — `composables/useBattle.ts`

- 배틀 폼: 팔라피는 처음엔 노멀폼, 한 번 물러나면 마이티폼 고정. 킬가르도는 공격기를 쓰면 블레이드폼, 킹실드·교체 시 실드폼.
  필드 패널의 체크박스로 수동 전환 가능. 턴은 행동 순서대로 처리하므로 킬가르도가 먼저 공격하면 같은 턴 뒤에 맞는 공격은 블레이드폼으로 계산
  (예상 표도 같은 규칙: `formAtHit`. 킹실드를 쓰면 실드폼)
- 변신(메타몽): 괴짜는 등장 시 맞은편 칸(`N−1−칸`), 변신 기술은 대상, 필드 패널 체크로 수동. 상대의 종(메가·폼 포함)·타입·특성·기술·
  실능치(HP 제외)·랭크를 복사, 도구·HP 는 자기 것 → 상대가 구애스카프여도 그 효과는 복사되지 않고, 메타몽의 스카프는 복사한 스피드에 적용.
  물러나면 해제
- 위협: 등장 시(선두 포함, 메가진화로 얻은 경우 포함) 상대 필드 공격 −1. 정신력/둔감/마이페이스/배짱 무효, 파수견 공격 +1, 주눅 스피드 +1,
  그 외 반응은 아래 랭크 변화 규칙. 선두를 고르는 중에 바꾸면 이전 선두의 위협 효과를 되돌림
- 랭크 변화(`statChange`, 기술의 확정 랭크 효과·위협·특성 반응에 적용. 화면의 +/− 수동 조절은 그대로):
  심술꾸러기 반대로 / 상대가 내린 경우 클리어바디·하얀연기·메탈프로텍트 무효, 괴력집게(공격)·부풀린가슴(방어) 무효, 미러아머 반사,
  실제로 내려가면 오기 공격 +2·승기 특공 +2 / 하양허브는 기술 하나의 변화가 끝난 뒤 내려간 능력치를 모두 되돌리고 소모
- 데미지를 받았을 때(입력한 데미지가 있을 때): 지구력 방어 +1, 깨어진갑옷(물리) 방어 −1·스피드 +2, 정의의마음(악) 공격 +1,
  열교환(불꽃) 공격 +1, 발끈(HP 절반 이하로 떨어지면) 특공 +1, 전기로바꾸기 → 충전, 모래뿜기 → 모래바람, 넘치는씨 → 그래스필드,
  독치장(물리) → 공격 측에 독압정. 쓰러뜨리면 자기과신 공격 +1. 턴 종료 시 가속 스피드 +1 (그 턴에 나온 포켓몬 제외, 선두는 1턴부터)
- 천정부지(메가저리더프): 쓰러뜨리면 가장 높은 능력(HP 제외 실능치, 같으면 공격→방어→특공→특방→스피드) +1. 땅 기술 무효는 위 "무효"
- 메트로놈(도구) 연속 횟수: 포켓몬별 마지막 기술·연속 횟수 기록, 교체하면 초기화. 총대장: 쓰러진 같은 편 수 (상대는 확인된 포켓몬만)
- 이번 턴 예상 (`useBattleAnalysis`): 대상 칸이 교체하면 들어오는 포켓몬을 대상으로 계산(잠복 적용), 애널라이즈는 대상보다 늦으면 적용
  (대상 교체 / 관찰한 선후공 / 우선도 → 스피드). 더블에서는 "모두보다 나중"이 아니라 대상과의 순서만 본다
- 도구 소모(`itemGone`, 계산에서 도구 없음으로 처리): 반감열매(해당 타입 효과굉장, 노말은 그냥), 풍선(맞으면), 기합의띠(내 쪽이 만피에서 HP 1).
  그 외(탁쳐서떨구기 등)는 필드 패널의 도구 이름을 눌러 수동 처리
- 더블: 같은 편 다른 칸이 도우미를 쓰면 이번 턴 예상 데미지 1.5배, 맞는 포켓몬의 아군이 프렌드가드면 0.75배
- 더블 아군 피해: 대상이 `allAdjacent`(지진/파도타기/방전/대폭발 등)인 기술은 행동 패널에 아군 피해 입력칸 + 예상 데미지(광역 0.75배,
  텔레파시 무효)가 나온다. 입력값은 내 쪽 실수치 / 상대 쪽 %, 턴 적용 시 아군 HP 에 반영하고 맞았을 때 반응도 처리

## 포켓몬 성능표 — `utils/perfTable.ts`

레벨 50, 도구 없음(스피드의 구애스카프 제외), 날씨·필드 없음. 대상은 현재 레귤레이션 출전 가능 포켓몬 + 메가진화 (팔라피 = 마이티폼, 킬가르도 = 내구는 실드폼·결정력은 블레이드폼).
- 내구: H32 / B32 / D32 실능치, 물리내구 = H × B, 특수내구 = H × D (성격 보정 선택 시 방어·특방 각각 1.1배)
- 결정력: `powerIndex` × 타수 × 항상 급소 1.5. 도구 없음(메가진화는 메가스톤 → 애크러뱃 2배 없음), "속임수주사위 지님"을 켜면 그 도구로.
  타수(`hitsUsed`, 기술이 맞았다는 전제 — 첫 명중은 '명중' 페널티로 따로): 고정 횟수 그대로, 부자유친 1.25,
  2~5회 = 2·3회 35% / 4·5회 15%(기댓값 3.1, 스킬링크 5, 속임수주사위 4·5회 50%),
  찍찍베기 = 두 번째부터 매 타 명중 판정·빗나가면 끝(명중 90 이면 기댓값 6.51회, 스킬링크 10, 속임수주사위 4~10 균등),
  트리플악셀 = 1타 10% / 2타 9% / 3타 81%(위력 20·60·120 누적, 스킬링크·속임수주사위면 3타).
  타수가 랜덤이면 표에 기댓값(위)과 최소~최대(아래)를 같이 표시하고, 기술 고르기·정렬은 기댓값으로.
  기술마다 특성 후보를 모두 계산해 결정력·타입·페널티를 바꾸는 특성만 따로 둔다(스킨류는 바뀐 타입으로 분류).
  타입별로 S32+성격 값이 가장 큰 기술 → 페널티가 있으면 페널티 없는 것 중 가장 큰 기술을 차선으로.
  페널티: 반동(돌머리·매직가드면 없음), 자기 능력 하락, 반동 턴, 모으기, 기술 고정(역린 등), 사용 후 기절, HP 소모(철제광선·무릎차기류),
  조건부(속이기·기습·힘껏펀치·트림·애크러뱃 등), 명중 100 미만(복안 1.3·의욕 물리 0.8·노가드 반영), 타수 랜덤.
  제외: 속임수(상대 공격), 위력이 상대에 따라 정해지는 기술(위력 0 으로 들어 있는 무게·HP 비례 기술 등). 바디프레스는 방어에 SP·성격
- 스피드: 투자 5가지(S0 / S32 / S32+성격 / 스카프 S32 / 스카프 S32+성격, 메가는 스카프 없음) × 특성(쓱쓱·엽록소·모래헤치기·눈치우기·서핑테일 2배,
  곡예 2배(스카프와 같이 안 씀), 속보 1.5, 가속 +1랭크) 유무 × 없음 / 순풍 / 끈적끈적네트(−1랭크). `effectiveSpeed` 로 계산하고
  (종족값, 투자, 배율, 필드, 실수치)가 같은 경우를 한 줄로 묶는다
