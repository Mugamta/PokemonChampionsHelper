# 배틀 계산 규칙

포켓몬 챔피언스 = 9세대 계산식, **레벨 50, 개체값 31 고정**, 노력치 대신 **능력 포인트(SP)**: 스탯당 최대 32, 합계 66.
근거: Showdown `data/mods/champions/scripts.ts`. 검증: `tests/damage.test.ts` 가 @smogon/calc(9세대)와 16개 난수 전부 일치하는지 대조,
`tests/battle.test.ts` 가 배틀 진행(폼 전환·위협·도구 소모·도우미/프렌드가드·턴 경과·되돌리기)을 확인
(SP → 노력치 환산 `EV = 8·SP − 4` 이면 레벨 50 실능치가 챔피언스 공식과 같아진다).

## 실능치 — `utils/stats.ts`

```
HP   = 종족값 + SP + 75            (종족값 1 = 껍질몬 → 1)
그 외 = floor((종족값 + SP + 20) × 성격)    성격 110/100, 90/100
랭크 배율: +n → (2+n)/2, −n → 2/(2+n)
```
실전 스피드(`effectiveSpeed`): 랭크 → 날씨 특성(쓱쓱/엽록소/모래헤치기/눈치우기/서핑테일) ×2 → 곡예(도구를 잃으면) ×2 → 속보 1.5 → 구애스카프 1.5 → 순풍 ×2 → 마비 0.5

## KO — `utils/ko.ts`

- `koChance`: 16개 난수 N회 합 분포 → 처음으로 KO 확률이 0보다 커지는 N (확정/난수 N타)
- 기합의띠 / 옹골참(틀깨기면 무시): 만피에서는 첫 타가 최대 HP−1 → 확정 N타·연속기 KO 시점에 반영 (`holdsOnAtFull`)
- 연속기는 히트별 누적으로 몇 타째 KO 인지(`koHitIndex`), 접촉 반격(까칠한피부/철가시 1/8, 울퉁불퉁멧 1/6) 시뮬레이션(`simulateMultiHit`)
- 상태이상 턴 종료 데미지: 독 1/8, 화상 1/16(내열 1/32), 맹독 n/16, 매직가드/포이즌힐 0
- HP 배수 판정(파티 화면, 위에서부터 우선): 재생력 3n → 포이즌힐 8n → 대타출동+먹다남은음식/검은진흙 16n+1 → 먹다남은음식/검은진흙 16n
  → 자뭉열매 4n → 대타출동 4n+1 → 생명의구슬 10n−1 → 기본 16n−1 (모래바람·화상 1/16 최소)
- 명중률 (`utils/accuracy.ts`): 기술 명중 × 복안 1.3 / 의욕(물리) 0.8 / 노가드 필중 × 광각렌즈 1.1 / 줌렌즈(나중 행동) 1.2
  × 맞는 쪽 모래숨기·눈숨기(날씨) 0.8 / 반짝가루 0.9 × 번개·폭풍(비 필중·쾌청 50) / 눈보라(설경 필중) × 중력 5/3
  × 명중·회피 랭크 (공격 측 명중 − 맞는 쪽 회피, ±6, +n → (3+n)/3, −n → 3/(3+n)). 천진은 상대의 명중·회피 랭크 무시,
  날카로운눈은 상대 회피 랭크 무시 + 명중 하락을 막음. 필중 기술(명중 없음)은 랭크와 무관, 명중 100 기술은 영향을 받음
- 급소율: 단계 0 = 1/24, 1 = 1/8, 2 = 1/2, 3+ = 확정. 단계 = 급소율 높은 기술 + 대운 + 초점렌즈 + 대파(파오리류) + 기충전 2.
  전투무장·조가비갑옷 0, 확정 급소 기술·무도한행동(독 상대)·급소 체크 1
- 실전 KO 확률 (`koProbWithin`): 데미지 표의 확정/난수 N타 옆에 "실전 x%" = 빗나감 + 급소 난수 + 보통 난수(+ 변덕레이저 30% 위력 2배)를
  섞어서 N번 안에 쓰러뜨릴 확률. 마우스를 올리면 명중률·급소율.
  - 연속기·둔갑 (`attackDistribution` → `koProbUses`): 한 번 쓸 때의 누적 데미지 분포 = 첫 명중 판정 × 타수 분포(`hitsUsed`, 트리플악셀·찍찍베기의
    두 번째부터 명중도 배틀 명중률로) × 히트마다 따로 급소·난수. 기합의띠·옹골참은 첫 히트 뒤 HP−1, 둔갑은 첫 히트가 1/8 고정 (둘 다 첫 사용만).
    연속기는 "한 번 써서" 쓰러뜨릴 확률, 한 번에 못 쓰러뜨리면 처음 가능해지는 사용 횟수(최대 4)로 "실전 N번 x%". 변덕레이저+둔갑은 생략
  - 대타 뒤 (대타를 무시하는 소리 기술·틈새포착은 대타가 없는 것과 같음): 같은 분포에 대타 HP 를 넣어 계산 (`first.sub`, 깨질 때 넘긴 데미지는 버림).
    데미지 칸·예상 흐름에 "대타가 깨질 확률"(`Cell.sub.breakP`). 단타는 KO 확률 없음, 연속기는 한 번 써서 대타를 깨고 남은 타수로 본체까지 쓰러뜨릴 확률
- 결정력(`powerIndex`) = 최종 위력 × 보정 후 공격 × 자속 × 날씨 × 화상 × 생명의구슬
  - 파티 화면은 연속기면 전체 타수 합 (`hitsUsed` 배율, 타수가 무작위면 기댓값 = 성능표와 같은 기준). 스킬링크·속임수주사위·부자유친 반영
- 내구 지수(파티 화면) = floor(H × B(또는 D) / 0.411)

## 배틀 화면 분석

- **상대 배분은 추정만** (`useBattle` "상대 배분", 2026-10-24): 선출 화면의 상대 성격·능력 포인트(자동 배치·통계·직접 입력)는 추측이라 배틀에 쓰지 않는다.
  배틀 슬롯(`battleSlot`)은 SP 0·무보정으로 비우고, 실능치는 아래 "상대 배분 추정"이 주고받은 데미지·선후공 관찰로 좁힌 범위(`useOppEstimate.bounds`)로 정한다.
  관측이 없으면 능력치마다 SP 0 하락 성격 ~ SP 32 보정 성격 (스피드는 스피드 구간 그대로, 관찰이 없으면 하락 성격 S0 포함)
  - 데미지 표·예상 흐름 (`combatantRange` → `useBattleAnalysis.rangedCell` → `spanCells`): 범위의 양 끝 두 배분으로 계산해 합친 범위.
    상대가 맞을 때 = 관측과 맞는 (HP, 방어/특방, 성격) 조합 중 H×B(D)가 가장 작은 / 큰 조합 (`statInference.bulkBounds`, SP 합 66 제한 포함),
    상대가 공격할 때 = 공격·특공·방어(바디프레스)의 최솟값 / 최댓값. 칸의 데미지·% 는 둘을 합친 범위, KO 판정은 둘이 다르면 "유리 ~ 불리"(`Cell.bounds`),
    예상 흐름의 쓰러뜨림 판정은 불리한 쪽도 쓰러뜨리면 확정 / 유리한 쪽도 못 쓰러뜨리면 없음 / 그 사이 난수 (각자 자기 최대 HP 로 % 환산)
  - 값 하나가 필요한 곳 (상대 HP % ↔ 실수치: 반동·흡수·대타·아픔나누기 등, 바디프레스·속임수, 실능치 비교 특성): 범위의 가운데 (`resolveAt`)
  - 상대 패널의 실능치는 범위로 표시. 변신한 상대는 복사한 실능치 그대로 (HP 만 자기 범위의 가운데)
  - 배분 시나리오 표(무보정 / H32 / H32·B(D)32 / 보정)·② 시나리오 흐름은 정해 둔 가정이라 그대로
- 상대 배분 시나리오(내 공격): 무보정 / H32 / H32·B(D)32 / H32·B(D)32 보정
- 이번 턴 예상(예상 흐름·행동 칸 예상 데미지·입력 경고)은 그 행동 직전 상태로 계산 (`useBattle.turnStateBefore`):
  교체로 나오는 위협, 먼저 행동하는 기술의 확정 효과·확률 100% 부가효과(랭크 — 매지컬플레임·바크아웃·얼어붙은바람·인파이트 반동 등,
  상태이상 — 도깨비불 등, 리플렉터·빛의장막·오로라베일, 날씨, 필드, 흑안개)와 행동 칸에서 체크한 상태이상.
  빗나감·데미지 0·상성 무효·대타·인분·우격다짐·황금몸이면 없음. 행동 순서 자체는 턴 시작 시점 스피드 기준 그대로
  (실제 턴 적용은 원래부터 순서대로 상태를 바꿔 처리). 분풀이의 "이번 턴 능력 하락"도 확률 100% 부가효과 포함
- 데미지 입력 경고 (`useBattleAnalysis.amountWarning`): 입력한 데미지가 계산 범위(상대 배분 추정 범위 + 추측 도구, 급소 체크면 급소 기준)에서
  ±1(상대 %p / 내 HP) 넘게 벗어나면 입력칸 아래에 범위를 보여 준다. 막지는 않음 (턴 적용 가능 — 입력값이 배분 추정의 근거).
  쓰러뜨린 입력은 최대 데미지가 남은 HP 이상이면 통과, 대타가 받는 경우·고정 데미지는 검토 안 함
- 메가진화는 진영당 한 번 (`useBattle.canMegaEvolve` / `sideMegaUsed`): 한 마리가 메가진화하면 같은 편 다른 포켓몬은 메가진화·메가 미리보기 불가
  (미리보기 중이던 것도 끔). 더블에서 두 칸이 같은 턴에 체크할 수 없게 막고, 둘 다 체크돼 있으면 앞 칸만
- 예상 데미지 표의 메가 폼 (`useBattleAnalysis.megaPreviewable`): 그 진영이 아직 아무도 메가진화하지 않았고 메가스톤으로 메가진화할 수 있는
  포켓몬(대기 중 포함, 쓰러진 포켓몬 제외)은 메가 폼도 함께 보여 준다. 예상 데미지 표 = 내 쪽 미리보기 버튼 추가·상대 열 추가,
  받는 데미지 표 = 내 쪽 열 추가·상대(분석 대상) 기술 줄 추가. 대기 포켓몬의 메가 토글은 없다 (필드 패널에서만)
- 행동 순서 (`useBattle.turnOrder`): 우선도(장난꾸러기·질풍날개·힐링시프트 포함) → 관찰한 선후공 → 선후공 판정(아래) → 상대 스피드 범위의 가운데(트릭룸이면 역순, 매직룸이면 스카프 없음).
  선후공 판정으로 모르는 경우 화면(행동 패널)은 본 순서를 고르기 전까지 "이번 턴 적용"을 막는다 (분석 대상 칸끼리, 같은 우선도의 기술끼리).
  더블의 나머지 짝은 범위 가운데 스피드로 처리.
- 맞는 포켓몬 (`useBattle.hitTarget`): 대상 칸이 이번 턴 교체하면 들어오는 포켓몬, 대상이 먼저 교체기(유턴·볼트체인지·배턴터치 등, 행동의 "공격 후 교체")로
  물러나면 그때 나오는 포켓몬 (예상 데미지·잠복·예상 흐름에 "물러나고 ○○이(가) 나옵니다" 줄). 들어온 포켓몬은 그 턴 메가진화하지 않음
  메가진화는 행동 전에 모두 처리하므로 메가 후 스피드로 비교
- **상대 스피드 구간** (`utils/speedInference.ts`): 무보정 / 성격 보정 / 무보정+스카프 / 보정+스카프 4구간마다 가능한 스피드 SP 범위(0~32)를 둔다.
  한쪽만 교체한 턴은 교체가 항상 먼저라 관찰 칩이 그쪽으로 고정(스피드 정보 없음), 둘 다 교체한 턴은 먼저 교체한 쪽 =
  나가는 포켓몬끼리의 스피드 비교로 관찰(메가진화 전). 같은 우선도에서 관찰한 선후공 = "상대 실전 스피드 ≥ / ≤ 내 스피드" → 랭크·순풍·마비·특성(쓱쓱 등)·곡예를 반영한 실전 스피드로 바꿔
  구간마다 SP 범위를 교집합으로 좁힌다 (동속은 양쪽 다 가능). 남은 구간으로 결론: 스카프 확정/아님, 성격 보정 확정/무보정 확정, 모두 불가(입력 확인).
  변신한 상대는 복사한 스피드 기준(스카프 유무만). 스피드 하락 성격은 다루지 않음.
  상대 도구를 확정하면 스카프 여부도 확정 (스카프면 스카프 구간만, 다른 도구면 스카프 없는 구간만)
- **선후공 판정** (`useBattle.speedOrder`, `utils/speedInference.ts` `oppSpeedSpan`/`compareSpeed`): 같은 우선도면 상대 스피드 구간을
  지금 조건(랭크·마비·순풍·날씨·필드·이번 턴 메가진화, 가능한 특성 전부 — 모르면 종의 특성 모두)으로 실전 스피드 범위로 바꿔 내 스피드와 비교.
  범위가 전부 아래/위면 선후공 확정 (관찰한 선후공이 다음 턴에도 이어지고, 교체·랭크·마비 등으로 조건이 바뀌면 자동으로 다시 판정),
  최댓값/최솟값이 내 스피드와 같으면 "동속 가능", 범위가 걸치면 모름 (예상 흐름은 각자 먼저 맞힌다면의 결과만, 본 순서를 입력받음). 관찰이 한 번도 없으면 하락 성격 S0 도 최솟값에 넣음.
  나중에 움직일 쪽에 선제공격손톱(상대 도구 미확정이면 가능)·퀵드로가 있으면 "바뀔 수 있음" 안내 (먼저 움직일 쪽의 손톱은 무관).
  행동 패널 선후공 칩은 기술을 아직 안 골랐어도 우선도 0 으로 보고 고정 표시 (예상 흐름과 같은 기준). 선공하수(트집)는 판정하지 않음.
  `turnOrder` 와 예상 흐름이 이 판정을 쓰고, 그 턴에 관찰한 선후공 입력이 가장 우선
- **상대 배분 추정** (`utils/statInference.ts`, `composables/useOppEstimate.ts`): 턴을 적용할 때 관측을 저장
  (기술·입력 데미지·급소·양쪽의 그 시점 폼/랭크/상태/HP/도구 소모·필드·상황 옵션).
  - 내가 준 데미지(%) → (HP SP 0~32) × (방어 또는 특방 SP 0~32) × (성격 −/무/+) 격자에서 16개 난수 중 하나가 맞기 전/후 화면 %(버림 표시)로 가능한 실제 데미지 범위 안인 칸만 남김 (`utils/hpDisplay.dealtHpRange`).
    쓰러뜨렸으면 최대 난수 ≥ 남은 HP 만 확인. 원더룸이면 반대 능력치
  - 내가 받은 데미지(HP) → (공격·특공 SP) × (성격) × (도구 후보: 없음 / 생명의구슬 / 달인의띠 / 힘의머리띠 / 박식안경 / 그 타입 강화 도구) 격자,
    난수 중 하나가 입력 ±1 HP. 상대 도구를 확정했으면 그 도구 하나로만 (선출 화면 도구는 추측이라 후보로 계산). 스피드가 스카프 확정이면 데미지 도구 제외,
    데미지 도구가 확정되면 "스카프 아님"
  - SP 합 66: 스피드·공격에 확실히 쓴 SP 를 빼고 남은 만큼만 HP·방어·특방 조합 허용
  - 제외: 연속기, 고정 데미지 기술, 변신한 상대. 상대 특성은 입력값, 도구는 확정한 것 기준 (도구가 드러나면 "상대 도구 확정"으로 고른 뒤 턴 적용)

- 상대 HP: 게임은 HP % 를 **버림**으로 표시한다 → p% = 실제 [p%, (p+1)%) (`utils/hpDisplay`: 예상 흐름의 쓰러뜨림 판정, 상대 패널의 HP 실수치 범위, 배분 추정, 계산용 실수치 = 범위의 가운데).
  턴을 적용하면 정수 %로 맞춘다 (턴 끝 회복·반동 등은 추정 최대 HP 의 가운데로 실수치를 거쳐 소수가 남음, 남아 있으면 최소 1%). 화면 % 에서 시작한 값은 실제가 평균 p+0.5 라 반올림(= p+0.5 를 버림),
  턴 시작에 가득 찼고 이번 턴 화면 % 를 입력하지 않은 포켓몬은 실제 값을 알아서 버림 (100% → 모래바람 5.96% → 94%).
  추정 최대 HP 가 실제와 다르면 턴 끝 데미지 결과가 1% 어긋날 수 있다 (예: 38% → 모래바람, 최대 HP 151 이면 32%, 142 면 33%) → 게임 화면 값으로 고쳐 입력
- **턴 끝 HP 관측** (HP 실능치 추정): 턴 적용 때 턴 끝 HP 변화 중 최대 HP 비율로 바뀐 것(모래바람·먹다남은음식·씨뿌리기 등 `residualPlan`, 상태이상 데미지)을
  `MonState.hpCheck` 에 기록 (시작이 가득 / 화면 % 그대로이고, 다른 HP 변화(열매·흡수 회복 등)가 섞이지 않았을 때만 — 추정 최대 HP 로 다시 계산해 결과가 같은지 확인).
  다음 턴 적용 전에 상대 HP 를 예상과 다른 정수 %(2%p 이내)로 고치면 관측 → 그 결과가 나올 수 있는 HP SP 만 남김 (`utils/hpDisplay.hpStepsMatch`, 고친 즉시 반영,
  다음 턴 적용 때 `hpObs` 로 저장). 내구 격자의 HP 축에 마스크로 적용 (`bulkSummary`/`bulkBounds` 의 `hpMask`). 추정 초기화로 지움
- 상대 도구: 배틀 계산은 "상대 도구 확정"으로 확정한 도구만 쓴다 (배틀 상태에만 저장, 선출 화면 파티는 그대로. 메가스톤은 예외로 그대로).
  도구 확정 선택지는 메가스톤이 맨 위, 비율은 원종 + 메가 폼 통계를 사용 수로 합친 값 (`formItemUsage`, Smogon 통계는 메가 폼을 따로 세서 원종 표에는 메가스톤이 없음).
  선출 화면의 도구(자동 배치·통계·직접 입력)는 추측 → 데미지 칸에 "○○이면 a~b% · N타"로 따로 보여 주고,
  예상 흐름은 추측 도구면 KO 판정이 달라질 때 "난수", 추측 구애스카프로 선후공이 바뀌면 안내. 패널의 도구 옆 "추측" 표시.
  소모·턴 끝 회복·연장 도구·아름다운허물 같은 확정 처리에는 쓰지 않음. 스피드 추정은 원래부터 스카프 있음/없음 구간을 모두 계산

### 선택지
- 내 쪽: 남은 PP 가 있는 기술(앙코르·구애 도구로 묶였으면 그 기술만, 속이기·만나자마자는 나온 첫 턴만, 도발 중이면 변화기 빼고) — 교체기(유턴·볼트체인지·막말내뱉기 등)는
  들어갈 대기 포켓몬마다 따로 — + 교체(교체 불가 상태가 아니면). 메가진화할 수 있으면 메가진화한다고 본다 (상대도)
- 상대 쪽: 쓴 기술(확정) + 선출 화면 기술 + 공개된 대기 포켓몬으로 교체
- 상대 선택지 비중 (`responseWeights`): 사전 비중(기술 = 확정 1 / 싱글 사용률 통계의 채용률, 없으면 0.5 / 교체 = oppSwitch) ×
  exp(smart × (그 선택지가 상대에게 주는 가치 − 최고 가치)). 가치 = 내 선택지 전체에 대한 내 점수 평균의 반대 (1턴 결과표 기준).
  즉 상대는 자기에게 유리한 선택을 더 자주 고른다고 본다 (데미지가 없는 랭크업·회복도 가치대로)

### 계산 조건
- 상대 배분은 추정 범위의 양 끝(데미지는 합친 범위, KO 확률은 평균), 확정 전 도구는 선출 화면 도구(추측)
- 선후공: 우선도 → 스피드(상대 스피드 범위 안에서 내 위치의 비율과 선출 화면 스피드 비교의 평균, 트릭룸 반대)
- 한 칸은 경우를 나눠 계산 (`evaluate`): 교체(내 쪽 → 설치기, 상대 쪽 → 설치기) → 먼저 움직이는 쪽 행동 → 나중 쪽 행동 → 턴 끝 회복
  - 행동할 확률: 반동·게으름 0, 잠듦·얼음은 이번 시도에 풀릴 확률, 마비 87.5%, 혼란 67%, 헤롱헤롱 50%
  - 공격: 쓰러뜨리는 경우 / 못 쓰러뜨리는 경우(그때의 기대 데미지 = (남은 HP 로 자른 기대 데미지 − KO 확률 × HP) / (1 − KO 확률)).
    데미지는 난수 균등 가정, 명중 포함, KO 확률은 계산 칸의 실전 KO 확률(명중·급소 포함)
  - 먼저 맞히면 상대 행동을 막는 확률: 풀죽음(하늘의은총 2배, 우격다짐·정신력·인분이면 없음) + 잠들게 하는 변화기
  - 반동(돌머리·매직가드 제외)·흡수(큰뿌리 1.3배) = 준 데미지 × 비율 × (맞는 쪽 최대 HP / 공격한 쪽 최대 HP), 생명의구슬 1/10 (막힌 공격은 없음)
  - 방어류는 연속이 아니면 상대 공격을 막음, 회복기는 턴 끝 회복(잃은 만큼까지), 기습·번개펀치(thunderclap)는 상대가 변화기·교체면 실패
  - 교체기: 행동한 뒤 살아 있으면 대기 포켓몬이 들어옴 (설치기 데미지). 먼저 썼으면 상대 공격은 들어온 포켓몬이 받는다
  - 도발을 먼저 맞히면 상대의 이번 턴 변화기는 실패 (반대도), 흑안개를 먼저 쓰면 이번 턴 상대 공격도 랭크 없이
  - 길동무: 먼저 쓰고 이번 턴 상대 공격에 쓰러지면 상대도 쓰러짐 (연속 사용은 실패)
- 점수 = (상대가 잃은 HP − 내가 잃은 HP) + ko × (쓰러뜨릴 확률 − 쓰러질 확률) + hazard × 설치기 가치 + (1턴) duel × 턴 뒤 맞대결 전망.
  교체기·교체로 여러 포켓몬이 다치면 각자의 HP 비율을 더함
- 2턴: 둘 다 살아서 턴이 끝나는 경우(교체기로 바뀌었는지 × 맞는 쪽 효과가 생겼는지별, 확률 5% 이상)마다 그 상태에서 다음 턴을 1턴 방식으로 다시 계산해
  내 최선 선택지의 기대 점수를 맞대결 전망 대신 더한다. 다음 턴 상태: 턴 뒤 HP(2% 단위), 랭크·상태이상·벽·순풍·구애 고정·앙코르·도발·하품·대타·씨뿌리기·도구 잃음,
  날씨·필드·트릭룸, 쉬던 턴 하나 줄임, 메가진화 사용 여부, 나온 첫 턴(속이기). 비중 5% 미만 상대 선택지·경우는 맞대결 전망으로.
  같은 상태는 기억해 두고 다시 쓴다
- 턴 뒤 맞대결 전망 (−1 ~ 1, `duelValue`): 턴 뒤 HP 로 서로 가장 센 기술(한 번 기대 데미지)을 주고받을 때 먼저 쓰러뜨리는 쪽이 이김,
  이기면 0.5 + 0.5 × 남은 HP. 반영하는 변화:
  - 확정 랭크 변화 (칼춤·용춤·용성군 특공 −2·막말내뱉기 등), 새로 친 벽 (리플렉터·빛의장막·오로라베일 — 설경일 때만)
  - 상태이상 (변화기는 명중률, 공격기는 명중 × 부가효과 확률 — 하늘의은총 2배, 우격다짐·인분 없음, 타입·특성·가루 기술·미스트/일렉트릭필드 면역):
    화상은 데미지 계산, 마비는 스피드 절반, 잠듦은 처음 몇 턴 행동 불가 (`skipDist`, 챔피언스 규칙 0 → 33 → 100%, 이미 잠든 포켓몬은 시도 횟수부터)
  - 파괴광선류는 다음 한 턴 행동 불가, 구애 도구는 이번 턴 쓴 기술로 고정 (상대는 추측 도구가 구애여도)
  - 날씨·필드·트릭룸: 기술(나중에 움직인 쪽이 남음)과 교체로 들어온 포켓몬의 등장 특성(가뭄·잔비·모래날림·눈퍼뜨리기·~메이커, 원시 날씨면 안 바뀜).
    등장 특성은 이번 턴 공격에도 반영. 날씨·필드 스피드 특성(쓱쓱·엽록소·모래헤치기·눈치우기·서핑테일)은 2배
  - 순풍: 새로 불면 그 진영 스피드 2배
  - 앙코르: 맞을 때 마지막 기술(내가 먼저면 지난 턴 기술, 나중이면 이번 턴 기술)에 고정 — 변화기면 2턴 공격 못 함, 공격기면 그 기술만. 아로마베일 무효
  - 도발: 변화기를 못 씀 (둔감·아로마베일 무효) — 2턴에서 다음 턴 선택지에 반영
  - 하품: 다음 턴 끝에 잠듦 (필드에 남아 있으면). 맞대결 전망에서는 70%만 잠드는 것으로 (교체로 피할 수 있어서), 2턴에서는 다음 턴 끝에 잠든 상태로
  - 대타: HP 1/4 을 내고(이미 있거나 1/4 이하면 실패), 먼저 깔았으면 이번 턴 상대 공격·변화기를 막고, 나중에 깔았으면 맞대결에서 공격 한 번을 막음.
    지금 깔린 대타는 맞대결에서 한 번 막아 주는 것으로 셈(이번 턴 상대가 공격하면 깨진 것으로)
  - 씨뿌리기: 풀 타입 제외, 매 턴 1/8 데미지 + 흡수 / 저주(고스트): HP 1/2 을 내고 상대는 매 턴 1/4
  - 탁쳐서떨구기: 맞은 쪽 도구 없음 (끈적끈적·메가스톤 제외) / 트릭·바꿔치기: 내가 구애 도구면 상대는 이번 턴 기술로 고정(변화기면 2턴 공격 못 함)되고 원래 도구를 잃음
  - 등장 시 위협: 교체로 들어오는 쪽(내 교체·교체기·쓰러진 뒤 교체, 상대 교체)이 위협이면 상대 공격 −1 (정신력 등 무효, 오기·승기·주눅·파수견 반응) — 이번 턴 공격에도 반영
  - 턴 끝 회복·데미지 (한 턴 몫을 매 턴 데미지에 더함): 독·맹독 1/8(포이즌힐은 회복), 화상 1/16(내열 1/32), 모래바람 1/16(바위·땅·강철·방진고글·관련 특성 제외),
    씨뿌리기 1/8 + 흡수, 저주 1/4, 먹다남은음식 −1/16, 검은진흙(독 −1/16 / 그 외 1/8), 그래스필드 −1/16 (매직가드는 데미지 없음)
- 데이터에 효과가 없어서 직접 반영한 기술 (`specialOf`, 양쪽 공통): 달빛·광합성·아침햇살(쾌청 2/3, 비·모래바람·설경 1/4, 그 외 1/2), 해수스파우팅(모래바람 2/3),
  희망사항(늦게 들어오는 만큼 0.4 로), 잠자기(가득이거나 잠듦·불면이면 실패, 가득 회복 + 2턴 잠듦), 저주(고스트 아니면 공격·방어 +1, 스피드 −1), 배북(HP 1/2 초과일 때 공격 최대),
  아픔나누기(두 HP 평균으로), 힘흡수(상대 공격 실능치만큼 회복, 공격 −1), 흑안개(양쪽 랭크 0), 길동무, 울부짖기·날려버리기·드래곤테일·업어후리기(공개된 대기 포켓몬 중 하나로 바뀜, 설치기 데미지),
  안개제거(양쪽 설치기 치움)·고속스핀·킬러스핀·정리정돈(내 쪽 설치기 치움) — 치운 설치기는 앞으로 들어올 포켓몬이 밟을 데미지만큼 가치
- 설치기 가치 (HP 비율 단위): 앞으로 들어올 포켓몬(상대 = 공개된 대기 + 아직 안 나온 선출 수, 종을 모르면 바위 등배·땅에 있음)이 받을 데미지 합 × 0.7.
  스텔스록 1/8 × 바위 상성, 압정 겹수만큼 늘어나는 몫, 독압정 0.1 (두 번째 0.05), 끈적끈적네트 0.05. 이미 다 깔렸으면 0. 상대가 내 쪽에 까는 것은 빼기
- 기대값 추천 = 상대 선택지 비중으로 평균한 점수 1위, 안전 추천 = 비중이 plausible 이상인 상대 선택지 중 최악의 점수가 가장 나은 것
- 내 포켓몬이 쓰러져 교체할 차례: 대기 포켓몬마다 설치기 데미지 + (1턴) 맞대결 전망 / (2턴) 들어간 뒤 다음 턴 최선값. 등장 특성(위협·날씨) 반영
- 가중치 (화면 "가중치"에서 바꿈, localStorage `pch_rec_weights`): ko 0.6 / duel 0.5 / hazard 1 / smart 3 / oppSwitch 0.3 / plausible 0.1. 깊이는 `pch_rec_depth`
- 계산 시간 (6 × 6 칸): 1턴 30~50ms, 2턴 200~300ms. 맞대결은 KO 확률 없이 데미지 범위만 계산, 배틀 상태 조회는 한 번 계산하는 동안 기억
- 보지 않는 것: 트집·회복봉인 등 나머지 특수 상태, 원더룸·매직룸·중력 바꾸기, 배턴터치의 랭크 넘기기, 상대의 교체기, 공개되지 않은 상대로의 교체,
  잠꼬대, 멸망의노래, 날씨 지속 턴, 세 턴 이상 앞의 수읽기, 더블

## 배틀 진행 자동 반영 — `composables/useBattle.ts` (구현은 `composables/battle/*`)

- 배틀 폼: 팔라피는 처음엔 노멀폼, 한 번 물러나면 마이티폼 고정. 킬가르도는 공격기를 쓰면 블레이드폼, 킹실드·교체 시 실드폼.
  필드 패널의 체크박스로 수동 전환 가능. 턴은 행동 순서대로 처리하므로 킬가르도가 먼저 공격하면 같은 턴 뒤에 맞는 공격은 블레이드폼으로 계산
  (예상 표도 같은 규칙: `formAtHit`. 킹실드를 쓰면 실드폼)
- 변신(메타몽): 괴짜는 등장 시 맞은편 칸(`N−1−칸`), 변신 기술은 대상, 필드 패널 체크로 수동. 상대의 종(메가·폼 포함)·타입·특성·기술·
  실능치(HP 제외)·랭크를 복사, 도구·HP 는 자기 것 → 상대가 구애스카프여도 그 효과는 복사되지 않고, 메타몽의 스카프는 복사한 스피드에 적용.
  물러나면 해제
- 위협: 등장 시(선두 포함, 메가진화로 얻은 경우 포함) 상대 필드 공격 −1. 정신력/둔감/마이페이스/배짱 무효, 파수견 공격 +1, 주눅 스피드 +1,
  그 외 반응은 아래 랭크 변화 규칙. 선두를 고르는 중에 바꾸면 이전 선두의 위협 효과를 되돌림
- **동시 등장 특성 순서** (`useBattle` "동시 등장"): 선두 / 같은 턴에 양쪽 교체 / 쓰러진 뒤 양쪽 교체는 함께 등장 →
  특성은 스피드 순(트릭룸이면 느린 쪽부터, 등장 시점이라 랭크 0·메가진화 전 폼)으로 발동하고 나중에 발동한 날씨·필드가 남는다.
  내 쪽 × 상대 쪽이 둘 다 등장 문구가 나오는 특성(날씨·필드·위협·프레셔·틀깨기 등 `ENTRY_MESSAGE`, 상대는 가능한 특성 중 하나라도)이면
  짝으로 묶어 `speedOrder` 로 판정, 모르면 상대 스피드 범위의 가운데로 임시 적용. 고칠 수 있는 묶음에서 상대 특성·도구를
  확정하면(스카프 아님 확정 등) 등장 직전 상태로 되돌려 다시 판정·발동한다 (`refreshEntry`). 행동 패널 "등장 특성 발동 순서"에서 본 순서를 고르면
  날씨·필드를 다시 발동(위협은 다시 안 함)하고 선후공 관찰과 같은 방식으로 상대 스피드 구간을 좁힌다 (같은 날씨끼리도 문구 순서로 판정,
  턴 수는 나중에 발동한 쪽의 바위 기준). 선두·쓰러진 뒤 교체는 다음 턴 적용 전까지 고칠 수 있고, 같은 턴 교체는 적용 전에 미리 고른다
- **흡수기 회복** (`useBattle.drainHeal`): 대상이 실제로 잃은 HP(쓰러뜨리면 남은 HP까지, 대타면 대타가 받은 만큼) × 비율(반올림, 최소 1).
  상대 HP 실수치는 추정 최대 HP 기준. 큰뿌리 1.3배(상대는 확정 도구일 때만), 회복봉인이면 없음, 대상이 해감액이면 그만큼 데미지(매직가드 제외)
  - 내 흡수기는 행동 칸 "흡수 후 내 HP"(HP 가 덜 찼고 회복봉인·해감액이 아닐 때)에 본 값을 넣으면 계산 대신 그 값으로 회복.
    회복량에서 상대가 잃은 실수치 HP 범위를 거꾸로 구해(`drainLostRange`) 관측(`drainLost`)에 기록 → 내구 격자에서
    `drainMatches` 로 최대 HP 를 좁힘 (쓰러뜨렸으면 잃은 HP = 맞기 전 남은 HP 라 화면 % 와 맞는 최대 HP 만 남음). 가득 찼으면 기록 안 함
- **턴 적용 때 HP 변화** (`useBattle` `afterAttack` / `hitPunish` / `hpMoveEffects` / `checkBerry` 등). 상대 HP 실수치는 추정 최대 HP 기준,
  상대 도구는 확정한 것만 (추측 도구는 반영 안 함)
  - 공격 후: 반동기 = 맞힌 데미지(대타 포함, 쓰러뜨리면 남은 HP까지) × 비율 반올림(돌머리·매직가드 제외) → 생명의구슬 최대 HP 1/10
    (매직가드, 우격다짐으로 부가효과가 없어진 기술 제외) → 조개껍질방울 맞힌 데미지 1/8 회복
  - 맞은 쪽 때문에: 접촉이면 까칠한피부 1/8·울퉁불퉁멧 1/6 (고정 타수 연속기는 타수만큼, 가변 타수는 1타로), 쓰러뜨리면 유폭 1/4(접촉)·
    내용물분출(맞기 전 HP). 매직가드 제외. 대타가 맞으면 없음
  - 흡수 특성: 저수·건조피부(물)·축전(전기)·흙먹기(땅) 기술을 무효로 받으면 1/4 회복
  - 회복기: HP회복·날개쉬기·태만함·우유마시기 1/2, 생명의물방울 1/4(더블은 아군도), 광합성·아침햇살·달의불빛 쾌청 2/3·다른 날씨 1/4·
    없으면 1/2, 꿀꺽 비축 1/2/3 → 1/4·1/2·전부, 치유파동 대상 1/2(메가런처 3/4). 회복봉인이면 없음
  - 힘흡수: 대상 공격 실능치(랭크 반영)만큼 회복 + 대상 공격 −1 (큰뿌리·해감액 적용, −6·대타면 실패).
    아픔나누기: 둘의 HP 합의 절반 (대타면 실패). 희망사항: 다음 턴 끝에 그 칸의 포켓몬이 쓴 포켓몬 최대 HP 1/2 회복
  - HP 소모: 배수의진 1/2 → 공격 최대 (1/2 이하·이미 최대면 실패), 스케일노이즈 1/3, 저주(고스트) 1/2 → 대상 저주
    (고스트가 아니면 공격·방어 +1 스피드 −1), 철제광선 최대 HP 1/2 반올림 (빗나가도, 매직가드 제외)
  - 자기 기절: 대폭발·자폭(빗나가도, 습기가 필드에 있으면 실패 — 틀깨기 제외), 추억의선물·목숨던지기(맞혔을 때),
    치유소원(교체할 포켓몬이 있을 때 → 다음에 그 칸으로 나오는 포켓몬이 HP·상태이상 모두 회복)
  - 자뭉열매(1/4)·오랭열매(10): 어떤 이유로든 HP 가 절반 이하가 되면 (숙성 2배, 볼주머니 +1/3, 상대 긴장감·회복봉인이면 안 먹음)
  - 재생력: 교체로 물러나면 1/3 회복. 대접: 등장하면 아군 1/4 회복
- **상대 특성 확정** (`useBattle.confirmAbility`, 행동 패널 "상대 특성 확정", 특성이 2개 이상인 포켓몬만, 메가진화한 상대는 특성이 고정이라 안 나옴. 선택지는 "미확정" + 특성들, 이 배틀 모드·현재 레귤레이션 사용률 통계에 있는 특성은 "(81.5%)"처럼 비율 — 사용률 표 `abilityUsage`): 배틀 상태에만 저장하고
  계산·선후공 판정·등장 특성 판정은 확정한 특성만 씀 (확정 전에는 선출 화면의 특성 = 추측, 패널에 "추측" 표시).
  특성이 바뀌면 예전 특성이 깐 날씨·필드를 지우고, 방금 나온 포켓몬(이번·지난 턴 등장)이면 새 특성의 등장 효과(위협·날씨·필드)를
  지금 적용 (동시 등장 묶음이면 짝·발동 순서도 다시). 잘못 추측해 이미 적용된 위협은 되돌리지 않음
- **쓰러진 뒤 교체**: 필드 포켓몬이 쓰러지고 교체할 포켓몬이 있으면 "쓰러진 포켓몬 교체" 패널에서 양쪽을 고르고 한 번에 등장
  (설치기 적용, 등장 특성은 위 순서). 고르기 전에는 턴을 적용할 수 없음 (예전처럼 교체 행동을 넣은 칸은 제외).
  상대 후보 = 공개된 포켓몬 + 공개 수가 선출 수보다 적으면 아직 안 나온 파티
- 랭크 변화(`statChange`, 기술의 확정 랭크 효과·위협·특성 반응에 적용. 화면의 +/− 수동 조절은 그대로):
  심술꾸러기 반대로 / 상대가 내린 경우 클리어바디·하얀연기·메탈프로텍트 무효, 괴력집게(공격)·부풀린가슴(방어) 무효, 미러아머 반사,
  실제로 내려가면 오기 공격 +2·승기 특공 +2 / 하양허브는 기술 하나의 변화가 끝난 뒤 내려간 능력치를 모두 되돌리고 소모
- 데미지를 받았을 때(입력한 데미지가 있을 때): 지구력 방어 +1, 깨어진갑옷(물리) 방어 −1·스피드 +2, 정의의마음(악) 공격 +1,
  열교환(불꽃) 공격 +1, 발끈(HP 절반 이하로 떨어지면) 특공 +1, 전기로바꾸기 → 충전, 모래뿜기 → 모래바람, 넘치는씨 → 그래스필드,
  독치장(물리) → 공격 측에 독압정. 쓰러뜨리면 자기과신 공격 +1. 턴 종료 시 가속 스피드 +1 (그 턴에 나온 포켓몬 제외, 선두는 1턴부터)
- 꼬르륵스위치(모르페코): 턴이 끝날 때마다 배부른모양 ↔ 배고픈모양, 물러나면 배부른모양
- 정정 / 교체: 헤더의 "상태 정정"을 켜면 필드 포켓몬을 바꿔도 교체 효과(설치기·등장 특성·물러남) 없이 상태만 고친다.
  끄고 바꾸면(선두 고르기 제외) 실제 교체로 처리
- 행동으로 인한 교체: 유턴·볼트체인지·퀵턴·막말내뱉기·바톤터치·셀프 오브 콜드·꼬리자르기, 상대 레드카드 → "공격 후 교체해서 나온 포켓몬",
  드래곤테일·배대뒤치기·울부짖기·날려버리기, 상대 탈출버튼·위기회피 → "공격 후 상대 쪽에서 나온 포켓몬". 기술 처리 순서대로 교체(설치기 적용),
  탈출버튼·레드카드는 소모. 도중에 교체된 포켓몬은 그 턴에 행동하지 않고, 바뀐 칸의 행동 입력은 비움
- 빗나감·실패 체크: 데미지 없음, 무릎차기·도끼차기·슈퍼셀슬램은 최대 HP 1/2 반동, 다음 턴 분함의발구르기·열불내기 2배
- 더블 광역기: 두 상대 칸 각각 피해 입력 (관측도 각각 기록)
- 비축(1~3)·기충전은 특수 상태로 기록 (기술을 쓰면 자동, 비축 칩은 누를 때마다 1→2→3→없음)
- 배틀 구성(선출·내 포켓몬·도구·상대 파티)이 바뀌면: 시작 전이면 새로, 진행 중이면 "이어갈 수 없음"을 알리고 확인을 누르면 초기화
- 확률 효과 체크 (각 행동 아래, `possibleInflicts`): 그 기술·도구·특성으로 맞은 쪽에게 생길 수 있고 걸릴 수 있는 것만 보인다 (내 기술 → 상대, 상대 기술 → 내 포켓몬).
  상대의 도구는 확정 전이면 추측 도구도 가능성에 넣는다 (예: 추측 왕의징표석 → 풀죽음 체크가 보임).
  기술 부가효과(확률 < 100), 트라이어택(화상·마비·얼음)·비몽사몽(독·마비·잠듦), 왕의징표석·악취(풀죽음 10%, 풀죽음 확률이 있는 기술과는 중첩 안 됨),
  독수(접촉 독), 사슬독(맹독). 인분·대타면 없음, 우격다짐이면 기술 부가효과와 (그 기술의) 왕의징표석 없음, 이미 걸렸거나 면역이면 제외,
  풀죽음은 상대가 이번 턴 아직 행동하지 않았을 때만(정신력 제외) → 체크하면 그 상대의 이번 턴 행동이 "행동 불가(풀죽음)". 속이다(100%)는 자동.
  여러 개 함께 체크 가능 (예: 오물폭탄 + 왕의징표석 → 독·풀죽음). 광역기는 다른 상대 칸도 따로 체크.
  접촉하면 맞은 쪽 특성(정전기·불꽃몸·독가시·포자·헤롱헤롱바디)으로 공격한 쪽에게 생긴 것도 체크 (원격·대타면 없음, 포자는 풀 타입·방진·방진고글 무효).
  예전의 "상태이상 발생" 선택 칸(양쪽)은 없앰 — 확정 효과는 자동, 그 밖의 이유로 생긴 상태는 패널의 칩에서 직접
- 확정 특수 상태 자동: 혼란(이상한빛 등)·도발·앙코르·트집·사슬묶기·헤롱헤롱·회복봉인(사이코노이즈)·조이기류(김밥말이·회오리불꽃 등)·문어굳히기·소금절이
  (이미 걸렸으면 그대로, 마이페이스는 혼란·둔감은 도발/헤롱헤롱 무효, 대타는 대타 무시 기술이 아니면 막음). 조이기류는 턴 끝 1/8
- 성별 (헤롱헤롱): 슬롯 성별(파티 화면·선출 화면 상대 입력에서 ♂/♀, 성별이 정해진 종은 데이터, 무성은 표시 없음).
  헤롱헤롱(기술)은 서로 다른 성별을 알면 자동, 같은 성별·무성이면 실패, 한쪽이라도 모르면 자동으로 걸지 않고 행동 아래 체크.
  헤롱헤롱바디는 접촉한 상대가 같은 성별·무성이면 체크 선택지 없음 (모르면 선택지 있음)
- 잠자기: HP 를 모두 회복하고 잠듦 (다른 상태이상은 풀림, HP 가득·이미 잠듦·잠들 수 없으면 실패). 정확히 2턴 자고 3번째 턴에 깸 (풀릴 확률 0% → 0% → 반드시)
- 변화기(하품·앙코르 등)는 데미지 입력칸 없이 빗나감·실패만. 남아 있던 데미지 값은 적용·검사에서 무시
- 이번 턴 확률 효과 (예상 흐름 패널): 입력한 기술의 부가효과 확률(하늘의은총 2배, 우격다짐 없음, 인분 막음, 이미 상태이상·타입 면역 생략),
  변덕레이저, 변덕쟁이(턴 끝 무작위 랭크 — 직접 입력 안내)
- 행동 칸 부가효과 체크 ("○○에게 생김"): 확률 효과는 생겼으면 체크 — 상태이상·풀죽음·혼란 + 랭크 변화(섀도볼 특방 −1, 코멧펀치 자신 공격 +1 등,
  키 `boost:{target|self}:{능력}={변화}`). 자기 쪽 랭크는 주 대상 칸에만, 상대가 쓰러져도 반영. 확정 효과·확률 100% 부가효과
  (매지컬플레임 특공 −1, 인파이트 자신 방어·특방 −1 등)는 체크 고정으로 표시만 하고 턴 적용 때 자동 (`useBattle.sureInflicts`).
  우격다짐·인분·대타면 해당 효과 없음. 체크한 효과는 같은 턴 뒤 행동의 예상에도 반영 (`turnStateBefore`)
- 기술 효과 자동 반영 (`applyMoveEffects`): 랭크 변화·상태이상·혼란 중 확정 효과와 확률 100% 부가효과
  (얼어붙는바람·바크아웃·암석봉인·니트로차지·진흙뿌리기·엄청난힘 등, 전기자석파·도깨비불 같은 변화기 상태이상 포함).
  공격기는 맞혔을 때만(빗나감·데미지 0·상성 무효 제외), 더블 광역기는 맞은 상대 모두. 부가효과는 우격다짐이면 없음, 인분이면 막음.
  상태이상은 이미 걸림·타입(전기 마비, 불꽃 화상, 독·강철 독, 얼음 얼음)·특성 면역(리프가드는 쾌청일 때, 플라워베일은 자신·아군 풀 타입, 스위트베일은 자신·아군 잠듦)·신비의부적·미스트필드면 안 걸림(잠듦은 일렉트릭필드도, 땅에 있을 때), 변화기는 황금몸이 막음.
  매직미러: 반사 가능 변화기(`reflectable`)의 랭크 하락·상태이상·혼란·씨뿌리기·하품은 쓴 쪽이, 상대 필드 설치기는 쓴 쪽 필드가 받음 (틀깨기면 반사 없음)
- 파괴광선류: 맞히면 다음 턴 "반동" 특수 상태, 그 턴 행동 기본값은 행동 불가(기타)이고 그 턴 끝에 풀림
- 게으름(특성): 기술을 쓰면(빗나가도) 다음 턴 "게으름" 특수 상태 → 반동과 같이 행동 불가(기타) 기본값, 그 턴 끝에 풀림
- 턴 끝 회복·데미지 (`residualPlan` / `applyResidual`): 먹다남은음식 +1/16, 검은진흙(독 +1/16, 아니면 −1/8), 그래스필드(땅에 있음 +1/16),
  아쿠아링·뿌리박기 +1/16, 젖은접시·아이스바디(날씨 +1/16), 건조피부(비 +1/8, 쾌청 −1/8), 포이즌힐(독 +1/8),
  씨뿌리기 −1/8 → 심은 쪽 칸의 포켓몬이 그만큼 회복(해감액이면 데미지). 회복봉인이면 회복 없음, 매직가드면 데미지 없음.
  도구는 잃었거나 매직룸·서투름이면 없음. **상대 턴 끝 도구 효과는 확정된 것만** — 행동 칸 아래 "상대 도구 확정"에서 이번 턴에 드러난 도구를 고르면
  배틀 상태에 확정으로 저장(선출 화면 파티는 그대로, 상대 패널 "확정"), 그 턴 처리부터 반영 (지우면 취소). 그라운드코트·날씨 연장 바위를 확정하면 그 포켓몬이 깐 5턴짜리 필드·날씨를 8턴으로 (직접 켠 필드·날씨는 깐 포켓몬을 모르므로 연장). 확정 전이면 예상 흐름 "턴 끝 예정"에 가능성만 표시.

- 행동 불가 (행동 칸 "행동 불가" + 이유 잠듦/얼음/마비/풀죽음/혼란 자해/기타): 기술 없음 (혼란 자해·기타는 입력한 HP 만 깎임). 이유가 잠듦·얼음·마비인데 상태이상이 없으면 그 상태이상으로.
  분함의발구르기·열불내기 2배 조건(지난 기술 실패)은 풀림. 잠듦·얼음이면 다음 턴 기본값도 행동 불가.
  잠듦·얼음인데 "기술 사용"으로 기술을 쓰면 깨어남·녹음 (잠꼬대·코골기는 잠든 채). 얼음은 불꽃 공격기·열탕·스팀버스트·열사의대지에 맞으면 녹음
- 바톤터치: 랭크 변화와 혼란·기충전·씨뿌리기·저주·뿌리박기·아쿠아링·회복봉인·대타·멸망의노래 카운트·전자부유를 나오는 포켓몬에게 넘김

- 대타출동: 최대 HP 1/4 를 깎아 대타 (HP 가 1/4 이하·이미 대타면 실패). 특수 상태 칩 "대타 n" = 남은 대타 HP (내 쪽 실수치, 상대 %), 직접 켜면 HP 소모 없이 1/4.
  대타 뒤에 있으면 입력한 데미지는 대타가 받고(0 이하면 사라짐) 본체 HP·맞았을 때 효과(열매·특성)·배분 추정 관측 없음.
  상대에게 거는 효과(랭크 하락·상태이상·혼란·씨뿌리기·하품·공격기 부가효과)와 위협을 막음. 소리 기술 등 대타 무시 기술(`bypasssub`)·틈새포착은 통과.
  꼬리자르기: 최대 HP 1/2(올림)를 깎아 대타를 만들고, 교체로 나오는 포켓몬이 대타를 받음.
  데미지 표·예상 흐름: 대타 뒤면 KO 타수 = 대타를 깨는 타수 + 본체를 쓰러뜨리는 타수 (대타 HP 를 넘긴 데미지는 버려짐, 연속기는 대타가 깨진 다음 타부터 본체).
  단타는 이번 공격으로 쓰러지지 않고, 예상 흐름에 대타가 사라지는지(확정/난수/남음) 표시. 데미지 칸에 "대타 n" (상대 대타 HP 는 % → 추정 최대 HP 로 환산).
  상대 대타가 받은 데미지는 게임에 숫자로 안 나오므로 행동 칸에는 어림한 % 를 입력 (대타가 사라졌으면 대타 HP 이상)
- 멸망의노래: 필드의 모든 포켓몬(방음은 쓴 포켓몬이 아니면 무효, 이미 걸렸으면 그대로) 카운트 3 → 턴 끝마다 1 줄고 0 이면 쓰러짐
- 전자부유: 5턴 동안 땅에 있지 않음 (땅 기술 무효, 압정·필드 영향 없음). 뿌리박기·중력이면 실패
- 소란: 3턴. 쓰면 잠든 포켓몬이 깨어나고(방음 제외) 그동안 아무도 잠들지 않음
- 혼란 자해 (행동 불가 이유 "혼란 자해"): 혼란이 붙고 스스로 잃은 HP 를 입력하면 반영. 예상 범위 = 위력 40·타입 없음·랭크만 반영한 자기 공격/방어, 난수 85~100% (도구·특성·화상·급소 없음, Showdown getConfusionDamage).

- 상태이상 (챔피언스 규칙): 독 1/8, 맹독 1/16 씩 늘어 최대 15/16, 화상 1/16 + 물리 위력 1/2(근성·객기 제외), 마비 스피드 1/2 + 몸저림 12.5%,
  잠듦은 행동하려 할 때 풀릴 확률 1번째 0% → 2번째 33% → 3번째 반드시, 얼음은 25% → 25% → 3번째 반드시.
  풀릴 확률 0% 인 시도(잠든 뒤 첫 시도 — 같은 턴 먼저 잠든 경우 포함, 잠자기는 2번째까지)는 "기술 사용"으로 골라도 기술이 나가지 않고 행동 불가(잠듦)로 셈 (잠꼬대·코골기 제외, `useBattle.sleepsThrough`). 행동 패널은 경고만 남기고 데미지·효과 입력을 숨기며(메가진화 체크는 그대로), 검사·예상 흐름(행동 불가 줄)·선후공 입력 요구에서도 빠짐

- 확률 안내("이번 턴 확률 효과"): 잠듦·얼음 풀릴 확률, 기술을 쓸 때 마비 12.5%·혼란 자해 33%·헤롱헤롱 50%

- 내 HP 는 실수치라 체력 전후 입력의 "맞기 전"은 지금 HP 로 고정 (상대 %만 고칠 수 있음)
- 배틀 결과 (`useBattle.battleResult`): 한쪽 필드가 전부 쓰러졌고 내보낼 포켓몬(`replaceOptions`)도 없으면 그쪽 패배, 둘 다면 무승부.

  기합의띠·옹골참(HP 가득)으로 반드시 버티면 HP−1, 둔갑(따라큐, 틀깨기·연속기 아님)이 막으면 최대 HP 1/8

- 하품: 맞으면 졸음(특수 상태 `yawn`) → 걸린 다음 턴이 끝날 때 필드에 있으면 잠듦. 교체하면 풀림(물러나면 특수 상태 초기화).

  그 외(탁쳐서떨구기 등)는 필드 패널의 도구 이름을 눌러 수동 처리
- 더블: 같은 편 다른 칸이 도우미를 쓰면 이번 턴 예상 데미지 1.5배, 맞는 포켓몬의 아군이 프렌드가드면 0.75배
- 더블 아군 피해: 대상이 `allAdjacent`(지진/파도타기/방전/대폭발 등)인 기술은 행동 패널에 아군 피해 입력칸 + 예상 데미지(광역 0.75배,
  텔레파시 무효)가 나온다. 입력값은 내 쪽 실수치 / 상대 쪽 %, 턴 적용 시 아군 HP 에 반영하고 맞았을 때 반응도 처리

## 포켓몬 성능표 — `utils/perfTable.ts`

레벨 50, 도구 없음(스피드의 구애스카프 제외), 날씨·필드 없음. 대상은 현재 레귤레이션 출전 가능 포켓몬 + 메가진화 (팔라피 = 마이티폼, 킬가르도 = 내구는 실드폼·결정력은 블레이드폼).
- 내구: 물리/특수 내구 지수 = H × B(D) ÷ 0.411 (파티 화면과 같은 식)을 무투자 / H32 / H32+B(D)32 / H32+B(D)32 성격 보정으로. 방어·특방 랭크 선택
- 결정력: `powerIndex` × 타수 × 항상 급소 1.5. 도구 없음(메가진화는 메가스톤 → 애크러뱃 2배 없음), "속임수주사위 지님"을 켜면 그 도구로.
  타수(`hitsUsed`, 기술이 맞았다는 전제 — 첫 명중은 '명중' 페널티로 따로): 고정 횟수 그대로, 부자유친 1.25,
  2~5회 = 2·3회 35% / 4·5회 15%(기댓값 3.1, 스킬링크 5, 속임수주사위 4·5회 50%),
  찍찍베기 = 두 번째부터 매 타 명중 판정·빗나가면 끝(명중 90 이면 기댓값 6.51회, 스킬링크 10, 속임수주사위 4~10 균등),
  트리플악셀 = 1타 10% / 2타 9% / 3타 81%(위력 20·60·120 누적, 스킬링크·속임수주사위면 3타).
  타수가 랜덤이면 표에 기댓값(위)과 최소~최대(아래)를 같이 표시하고, 기술 고르기·정렬은 기댓값으로.
  기술마다 특성 후보를 모두 계산해 결정력·타입·페널티를 바꾸는 특성만 따로 둔다(스킨류는 바뀐 타입으로 분류).
  타입별로 S32+성격 값이 가장 큰 기술 → 페널티가 있으면 페널티 없는 것 중 가장 큰 기술을 차선으로.
  페널티: 반동(돌머리·매직가드면 없음), 자기 능력 하락, 반동 턴, 모으기, 기술 고정(역린 등), 사용 후 기절, HP 소모(철제광선·무릎차기류),
  조건부(속이기·기습·힘껏펀치·트림·애크러뱃 등), 명중 100 미만(복안 1.3·의욕 물리 0.8·노가드 반영), 타수 랜덤.
  제외: 속임수(상대 공격), 위력이 상대에 따라 정해지는 기술(위력 0 으로 들어 있는 무게·HP 비례 기술 등). 바디프레스는 방어에 SP·성격
- 스피드: 포켓몬마다 S0 / S32 / S32+성격 / 스카프 S32 / 스카프 S32+성격 (메가는 스카프 없음). 스피드 특성(쓱쓱·엽록소·모래헤치기·
  눈치우기·서핑테일·곡예 2배, 속보 1.5, 가속 +1랭크)이 있으면 특성 줄을 따로 (곡예는 스카프와 같이 안 씀). 스피드 랭크 선택
- 결정력 페널티 체크: 체크를 끈 페널티가 있는 기술은 최고 기술로 고르지 않는다. 공격·특공 랭크 선택 (바디프레스는 방어 랭크)

## 상대 포켓몬 자동 배치 — `utils/autoSet.ts`

선출 화면에서 상대 포켓몬을 고르면(또는 "자동 배치" 버튼) 특성·도구·성격·능력 포인트·기술을 채운다. 규칙 전체는 파일 머리 주석.

- **사용률 통계 우선** (`usageSet`): 현재 레귤레이션의 Smogon 통계(`public/data/usage/`)에 있으면 원종·메가 폼 중 많이 쓴 쪽으로,
  많이 쓴 기술 4개·배분(최다 성격+능력 포인트)·특성·도구. 메가면 메가스톤 + 원종 특성, 도구는 같은 파티와 겹치면 다음 순위,
  기술이 4개가 안 되면 아래 규칙으로 채움. 통계가 없는 포켓몬만 아래 규칙

- 도구: 메가진화가 있으면 메가스톤(여러 개면 첫 번째), 없으면 도구 없음. 능력치·결정력은 메가 폼 기준
- 결정력: 파티 화면과 같은 `powerIndex` × 연속기 타수 기댓값
- 분류: 결정력 지수 p = 풀보정 최고 결정력 ÷ 30,000, 내구 지수 b = 풀보정 내구(H32 + 방어(특방)32 + 상승 성격, 물리·특수 평균) ÷ 70,000
  - p ÷ b ≥ 1.05 딜러형(AS·CS), < 0.85 내구형(HB·HD), 그 사이 딜포터형(HA·HC: H32 + 주력 32 + 높은 방어 2)
  - 내구형 비율이어도 결정력 3만 초과 또는 공격·특공 종족값 130 이상이면 딜포터형
  - 딜포터·내구형 중 p < 1, b < 1이고 스피드 종족값 100 이상이면 스피드형(HS: H32 + S32 + 높은 방어 2, 스피드 ↑ 성격, 기술은 내구형과 같음)
  - 쓸 만한 공격기 = 한 턴 휴식(파괴광선류)·모으기·자폭류·철제광선·조건부 기술·속임수 제외
- 특성: 풀보정 최고 결정력이 가장 높은 특성. 주력 공격 능력치는 종족값 비교 (천하장사·순수한힘은 공격 2배)
- 내구형 기술: 스텔스록 → 앙코르 → 하품 → 도발 → 날려버리기/울부짖기 → 회복기 순으로 3개 + 최고 결정력 기술(명중 90 이상) + 교체기
  - 위 지원기를 1개 이하로 배우면 빛의장막 → 리플렉터 → 전기자석파 → 희생기(추억의선물·치유소원·철제광선·대폭발 등)도
- 딜러형 기술: ① 최고 결정력 2개(기술 명중 90 이상, 서로 다른 타입, 하나는 자속기 — 명중 90 이상 자속기가 없으면 명중이 낮아도) ② 스피드 상승기 ③ 결정력 상승기 ④ 기술이 없는 자속 타입 ⑤ 비자속 최고
  ⑥ 선공기(우선도 → 자속 → 위력) ⑦ 전용기(한 종만 배우는 공격기, `exclusiveMoves`) ⑧ 자속 최고(한 턴 휴식 포함)
- 딜포터형 기술: ① ③ + 회복기 + ④ ⑤ + 교체기 + ⑥ ⑦ ⑧
- 회복기: 반피 회복기, 없으면 잠자기 + 잠꼬대 + 일격기 (세트, 셋 다 배우고 공격기도 함께 들어갈 칸이 있을 때만). 딜포터형은 최고 결정력 기술 + 세트
- 결정력이 같으면 명중 100(필중 포함) · 명중 외 페널티 없음 · 부가효과 있음 중 많이 해당하는 기술 우선
- ② 스피드 상승기(메가진화 전·후 특성에 가속이 있으면 생략): 주력도 오르는 것 → 랭크 합 → 공격기 순 (고속이동 < 니트로차지). 주력과 분류가 다른 공격기(특수형의 개척하기 등)는
  스피드 2랭크 이상·주력도 오르는 변화기를 배우면 쓰지 않음 (못 배우면 그대로 씀)
- ③ 결정력 상승기: 주력이 오르면서 랭크 합 2 이상인 변화기 또는 공격기. 랭크 합 → 스피드도 오르는 것 순
  - 랭크 합: 공격·특공 동시 상승은 하나로, 스피드는 몇 랭크든 1, 명중 포함. 변화기가 공격 능력치를 올리면 주력 쪽만
- 남는 칸은 결정력 순, 그래도 남으면 배우는 기술 id 순 (메타몽 = 변신). 기선제압·페인트는 넣지 않음
- 검토 기록: 내구 7만만으로 나누면 메가한카리아스 등 85마리가 내구형, 결정력 2만 7천으로 낮추면 아머까오·밀로틱 등이 공격형이 되어 채택하지 않음

## PP · 부른 기술

- 기술을 쓰면 `MonState.ppUsed` 에 기록 (빗나가도 1, 상대를 노리는 기술은 노린 상대 중 프레셔마다 +1 — 광역기·설치기는 필드의 상대 모두, 잠듦으로 못 쓰면 0, 교체해도 유지). 상대는 여기 + `movesSeen`(잠꼬대로 낸 기술)이 확정 기술
- 변신 중에는 복사한 기술 PP 5 를 `tfPpUsed` 에 따로 (변신이 풀리면 지움). 원한 −4 / 으스스주문(맞혔을 때) −3 은 대상의 마지막 기술, 과사열매는 PP 가 0 이 되면 10 회복 (최대 PP 까지)
- 잠꼬대·흉내내기 (`CALLER_MOVES`): `ActionState.via` = 부른 기술, `move` = 나간 기술. 데미지·효과는 나간 기술, PP·잠듦 판정·우선도·lastMove(앙코르)는 부른 기술
- 앙코르: 마지막으로 쓴 기술을 알면 행동 칸 기술을 고정 (턴 적용 때도 맞춤). 지속 3턴 (`encoreTurnsLeft` = 이번 턴 포함 남은 턴)
